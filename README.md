# Vikas Sampath Portfolio

Interactive 3D Developer Portfolio built with React, Vite, Three.js, and React Three Fiber.

## Live Site

```text
https://vikassampath.github.io/VS-Portfolio/
```

## Run Locally

```bash
npm install
npm run dev
```

Local URL:

```text
http://127.0.0.1:5174/
```

## Edit Your Details

Most personal content is in:

```text
src/portfolioData.js
```

Update your name, role, email, social links, skills, projects, and timeline there.

## Build

```bash
npm run build
```

## Deployment

The source code lives on `main`. The built static site is published from the `gh-pages` branch.
